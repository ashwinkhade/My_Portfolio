## 📌 Description

A fully animated, single-file personal portfolio website showcasing my skills, projects, experience, and certifications in **Data Analytics**, **Machine Learning**, and **Artificial Intelligence**.

Designed to be fast, responsive, and visually impressive — with a live AI chatbot powered by Claude (Anthropic) that answers questions about me in real time.

## ✨ Features

- 🎬 **Loading screen** that fades out on page load
- 🖱️ **Custom glowing cursor** with a smooth trailing ring
- 🌌 **Live particle network** canvas in the background
- ✨ **Hero name shimmer** gradient text animation
- 🃏 **3D floating card** with continuous tilt + float animation
- 📜 **Scroll reveal** on all sections (fade up, slide left, slide right) via IntersectionObserver
- 🏷️ **Skill level tags** (Advanced / Intermediate / Beginner) — no subjective percentages
- 🔄 **Infinite marquee** for companies and platforms
- 🎨 **Project cards** with top-border gradient sweep on hover
- 💫 **Pulsing ripple rings** on the contact section avatar
- 🤖 **AI Chatbot** (top-left, powered by Claude) — knows my full resume, fully animated
- 📬 **Contact form** that opens pre-filled email on submit
- 🎓 **Education section** with CGPA badge and course highlights
- 🏅 **Clickable certificate cards** with "View Certificate" buttons linking to real credentials
- 📱 **Fully responsive** — stacks to single column on mobile

## 🚀 Getting Started

### Option 1 — Just open locally
```bash
# No install needed — just open the file
open ashwin-portfolio.html
# or double-click the file in your file explorer
```

### Option 2 — Deploy on Netlify (drag & drop)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Rename `ashwin-portfolio.html` → `index.html`
3. Drag and drop the file
4. ✅ Live in 30 seconds

### Option 3 — Deploy on GitHub Pages
```bash
# 1. Create a repo named: yourusername.github.io
# 2. Upload index.html
# 3. Go to Settings → Pages → Enable
# 4. Live at: https://yourusername.github.io
```

### Option 4 — Deploy on Vercel
```bash
# 1. Push to GitHub
# 2. Import repo at vercel.com
# 3. Auto-deploys on every push
```
